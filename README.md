# Nozik-legal

Юридические документы приложения Nozik на трёх языках. Сайт собирает GitHub Pages (Jekyll).

| | Oʻzbekcha | Русский | English |
|---|---|---|---|
| Privacy Policy | [uz/privacy](https://oldschoolroyale.github.io/Nozik-legal/uz/privacy.html) | [ru/privacy](https://oldschoolroyale.github.io/Nozik-legal/ru/privacy.html) | [en/privacy](https://oldschoolroyale.github.io/Nozik-legal/en/privacy.html) |
| Terms of Use | [uz/terms](https://oldschoolroyale.github.io/Nozik-legal/uz/terms.html) | [ru/terms](https://oldschoolroyale.github.io/Nozik-legal/ru/terms.html) | [en/terms](https://oldschoolroyale.github.io/Nozik-legal/en/terms.html) |

Эти адреса зашиты в приложении (экран «Профиль»), поэтому не переименовывайте файлы.

- Контакты, имя разработчика и дата вступления в силу задаются в `_config.yml` и подставляются во все документы.
- Тексты лежат в `ru/`, `uz/`, `en/` в Markdown. Меняя документ, обновите все три языка и дату в `_config.yml`.
- Публикация: Settings → Pages → Deploy from a branch → `main` / `(root)`.
